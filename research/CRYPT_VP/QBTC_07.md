## Source audit and quantum evaluation bridge

Song, arXiv:1409.2187v1, https://arxiv.org/pdf/1409.2187, Sec. 5.1.1 pp. 9–11, Proposition 5.2 explicitly lifts Rompel's UOWHF reduction to quantum attackers. It describes balancing, hard-sibling reduction, amplification and compression. The classical complete proof is Katz–Koo, https://www.cs.umd.edu/~jkatz/papers/rompel.pdf. KQT arXiv:2411.02554v1, https://arxiv.org/pdf/2411.02554v1, Theorem 1 p. 2 explicitly invokes Song's fully black-box signature reduction. Definition 11(ii), Fact 13 and Proposition 28 give pointwise quantum evaluation and one-wayness with uniformly sampled public parameter for the trapdoor primitive. The ordinary qOWF input can be uniform (P,x), output (P,F(P,x)); inverting necessarily recovers the same P. The original OWF-to-UOWHF theorem is not itself an explicit circuit/resource audit for this KQT parameterization.

Quantum black-box simulation lemma: for fixed oracle O, an input-preserving unitary U coherently implements an amplified pseudodeterministic evaluation, with fresh work registers and designated output register. On every basis input x the correct output f(x) has probability >=1-e. Classical randomness and intermediate measurements can be purified and deferred. Apply U, XOR its output into a target register, then U†. For each x, the difference from ideal XOR-by-f(x) on the initialized-work subspace has vector norm <=2 sqrt(e): before uncomputation only the wrong-output projection (norm <=sqrt(e)) can differ, and two unitaries differ there by norm at most 2. The x register is preserved, so the branches are orthogonal and the same bound holds for arbitrary superpositions entangled with a reference. This is an isometry bound with fresh ancillas, not a claim about arbitrary uninitialized workspace. The induced channel's diamond-norm difference is <=4 sqrt(e); a polynomial-query hybrid has negligible distinguishing advantage with sufficiently amplified evaluation. Classical basis calls also admit the ordinary error union bound. Assume coherent access to the same classical oracle and reversible simulation with polynomial overhead, including its inverse. Thus where the published black-box lifting uses a deterministic function oracle, replacing it by the KQT evaluator is justified at this interface; an actual UOWHF circuit and exact size bounds still need a detailed Katz–Koo compiler implementation. No new full CR result or deployable oracle is claimed.

## Conditional tree binding theorem

Define TCR game: quantum adversary stage 1 outputs a classical target x and retains arbitrary quantum state; challenger draws an independent honest key K, gives K to stage 2; success if stage 2 outputs x' != x with H_K(x')=H_K(x). All parties may access the fixed KQT oracle in the same model. Assume quantum TCR advantage <=epsilon(lambda) for each efficient reduction below, for the required fixed-width domains. This is target-before-key security, not post-key arbitrary collision resistance.

External agreement first freezes a complete canonical batch, including domain/network, epoch/finality identity, fixed tree shape, leaf index, and any required transaction/output semantics. Use injective padded encodings in the permitted fixed-width domains; reject malformed encodings. A leaf may itself be hashed in its own level if necessary. At level l, every honest hash input tuple is fixed by the frozen leaves and lower-level outputs. Only then draw the independent uniform key K_l, shared across that level, and compute the next level. Use domain/shape/position tags where required; distinct keys and canonical encodings must be consistent with the actual TCR function's input length. The authenticated checkpoint contains context, shape, ordered keys, and root. The registry/root authenticity is an explicit external assumption. Never accept an attacker-supplied replacement manifest without checking that authentication. Store O(log L) keys for a balanced L-leaf tree (or a leaf-hash level plus those keys) and root; an inclusion proof uses O(log L) siblings. No concrete UOWHF byte sizes assumed. This is an archival/data-availability design with bounded polynomial-size batches.

Given a forged full batch or a changed leaf at a specified position with a classical accepted path under the identical manifest, compare the adversarial root input tuple to the honest one. If they differ, this is a TCR collision at the root. Otherwise the tuples agree; descend into a differing leaf's path, until reaching a node with equal output but differing input. A false leaf claim forces such a node. For full batch, choose one differing leaf; for inclusion proof, use its explicit position and supplied sibling values. The extracted target is always the honest input, which was fixed before the key for its level. A reduction guesses one of the Q honest hash nodes uniformly at the start, simulates the adversarial batch selection, samples keys at lower levels, commits that guessed node's honest input to the TCR challenger, uses challenge key for its whole level, and simulates other evaluations and later independent keys. It runs the adversary once (no rewind), extracts the first collision and wins if its guess matches. Thus tree forgery probability <=Q*epsilon in the ideal evaluation model, plus simulation error from polynomially many amplified quantum calls. This holds even if the adversary chose the batch before fresh keys, and sees all keys, honest paths, and honest batch afterward. If the TCR game allows a uniform polynomial bound across the family of reductions, the single guessed-node reduction has that bound; if tree shape varies, pad to a public polynomial node bound and abort on unused guesses. Distinct independent keys at each level matter: revealing all keys before the batch or reusing one key for parent inputs depending on it invalidates the simple reduction. The proof does not assert that every such alternative is insecure. Multi-epoch extension guesses an epoch as well, provided fresh keys per epoch and a polynomial bound on attempts.

## Key-grinding and selective-abort envelope

For fixed precommitted target, g independent fresh classical candidates, and efficient adversary allowed to select one candidate after seeing all keys, success <=g epsilon by a single-key reduction guessing the candidate and embedding the challenge there. This holds also with adaptive independent draws up to g if the target is held fixed. If an attempt may be discarded, report both unconditional success and success conditional on publication: P(win|published)<=min(1,g epsilon/P(published)), for positive publication probability. A conditional key law pointwise dominated by alpha times honest uniform key law increases a one-key event bound by alpha if the rest of the adversary state/experiment is generated identically conditional on the key. Statistical distance delta gives an additive delta for the same reason. Marginal key entropy alone does not bound correlation with adversary side information or target. Coherent quantum grinding is a different game; the classical-candidate bound does not apply automatically.

Toy exceptional-pair family: on N labels, key is an unordered distinct pair {a,b}; map both to a and keep other labels distinct. Fixed target has alternate opening iff key includes target, so exact probability 2/N. After the key, choosing a target in the exceptional pair succeeds with probability one. This finite toy is not compressing, and is not a claim of practical security. It is an ordering countermodel. A compressing analogue conditional on any secure TCR H on a large domain uses H_K(g_{a,b}(x)) with independently sampled exceptional pair: for a target fixed before both keys, either target is in pair (2/N), or a distinct alternate collides at H on the target's unchanged input. This adds <=2/N to TCR advantage, while arbitrary post-key collisions are trivial. For independent classical key draws in the finite toy, omniscient selection gives exactly 1-(1-2/N)^g.

## Ledger game and Bitcoin integration

Protocol phases: open -> raw target frozen by external agreement and data availability -> sequential independent public key draws with level targets fixed -> authenticated sealed manifest -> later opening checks. The finite simulator models a trusted registry and caller-supplied keys; it does not implement a beacon, finality, or honest entropy. Replacing the sealed manifest, changing network/finality context or key list must fail authentication. The same checkpoint on histories sharing its finalized prefix can be replayed; this is intentional and cannot serve as a one-time spend marker. Spend verification separately checks unspent status and authorization. A branch-specific context must come from external consensus, not from an unauthenticated claimed branch name. A finalized epoch may support archival compression of the agreed history, but new-node bootstrap, availability, fork choice, reorg liveness, rollback and initial finality are not solved by hashing. If the raw target was selected only by a previously unauthenticated short commitment, the argument is circular. TCR cannot simply substitute for every Bitcoin txid or address, nor for PoW. A fully classical public witness wrapper still falls under QBTC-01/02 under their hypotheses. Prospective design: quantum validators plus classical data and authenticated epoch finality, not an unchanged Bitcoin soft fork.

## Exact local pilot

qbtc07_check.mjs: exceptional-pair key game for N=8,16,32,64 and g=1,2,4,8,16. Every fixed target and key is checked; all post-key choices have a collision. In N=64 game one draw is 3.125%, 8 draws ~22.43%, 16 draws ~39.83%. These are exact rational toy probabilities, not estimates for real cryptography.

Four-leaf binary tree with two independent public level keys; 16 keys enumerate all 4-input-to-2-output functions. Across 65,536 full-batch pairs, 61,440 distinct pairs, 46,720 equal-root distinct pairs: extract a target collision in every equal-root alternate (29,184 at level 1, 17,536 at level 2). All 16,384 honest inclusion paths accepted. Enumerate 131,072 leaf/path combinations; 43,520 accepted wrong-leaf claims, each with a valid extracted target collision. These high forgery counts are expected from the tiny intentionally insecure family; extraction, not security, is being tested. Thirteen state-machine controls check key timing, immutable target/manifest, fork/network context, same-checkpoint replay and malformed proof rejection. Local execution passed. Independent replay is staged; no hardware, quantum oracle or native certificate.
