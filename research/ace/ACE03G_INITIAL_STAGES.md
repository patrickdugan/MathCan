# ACE-03G | First constructible stages and empty-set closure

Status: eight new closed derivations accepted by the executable ACE
object-language checker, including the relativized empty-set axiom
for the exact pinned L predicate. This joins the earlier extensionality
and foundation certificates. General transfinite recursion, uniform
definition adequacy and formal checker soundness remain open.

## Construction

Use the exact Def, Stage, StageGraph and L formulas generated by
constructible_definition.mjs. The default generator output and pinned
L_formula.json are unchanged; the optional internal export now
includes the stage rule. ACE-03F's finite witness builder provides
the named proof constructors, finite ordinal witnesses, Kuratowski
pairs, and one- and two-entry function graphs. Its original CLI
receipt still reproduces.

Let z be empty, o={z}, and n={z,o}, with z distinct from o,
Succ(z,o) and Succ(o,n). For Def(z,o), any member x of o equals z,
so it is empty and satisfies the first branch of the definability
predicate. Conversely, if D(z,x), the exact subset lemma gives
x subset z. Hence x is empty and extensionality identifies x with z,
which puts x in o. The equivalence proves Def(z,o) directly; no
general semantic adequacy theorem is used.

At index z, no predecessor belongs to z. The limit-stage rule
requires a union of no earlier values, which is empty. Both
directions of the membership equivalence follow by contradiction.
Construct f0={<z,z>} with domain o; its only index satisfies the
zero-stage rule. Construct f1={<z,z>,<o,o>} with domain n; at index
z the zero-stage rule applies, and at index o the successor rule
uses predecessor z and the proved Def(z,o). Finite graph
functionality and equality substitution give each required stage
witness. Thus the exact StageGraph formulas hold for these graphs.

The finite ordinal construction from ACE-03F supplies z,o,n and
the successor properties without any added axioms. The singleton
o is transitive, and each of its members is transitive, by
emptiness of z. Hence Ordinal(o). For any empty set x, ambient
extensionality gives x=z, so x belongs to o. With alpha=o,
domain=n, graph=f1 and stage value r=o, introduce the witnesses
in the exact pinned L(x) definition. This proves
forall x, Empty(x) -> L(x). Ambient Empty yields a witness to
exists x, L(x) and Empty(x).

The guard-conversion proof rewrites the L predicate as G with the
same class definition. Composing with ACE-03C's generic empty-set
closure implication gives a closed derivation of Empty^L.

Two goals are reconstructed independently. The compiler accepts a
five-node source conjunction of empty-set, extensionality, foundation
under the ZFC source policy with a 6,950-node ZF target proof.
This source example does not use choice. Nine negative controls
reject the wrong theory policy, wrong class definition, malformed
guard composition, missing empty-set certificate, and imports of
five remaining uncertified fixed axioms.

The checker has accepted explicit graph witnesses for the first
two stages. Uniqueness and existence of arbitrary ordinal-indexed
stage graphs, their coherence, monotonicity and identification
with the standard hierarchy require further object-level work.
The executable proof checker itself is not formally verified.

## ACE-03H gate

Prove agreement on overlapping domains for stage graphs using
bounded induction and uniqueness of Def. Then derive restriction
and extension lemmas, and build general stage graphs by Replacement
and Union. Establish monotonicity using inflation and the ordinal
ordering facts. These are prerequisites for the usual pair and
union closure arguments. Formal verification of the object checker
and uniform definability adequacy remain separate gates.
