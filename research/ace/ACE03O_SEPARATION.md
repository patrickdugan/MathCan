# ACE-03O | Finite relation compiler and bounded Separation instances

Status: the executable object-language checker accepts a syntax-directed
fixed-formula definability compiler, bounded-formula absoluteness
derivations, and four exact relativized Separation instances. This is
instance-level progress; the unrestricted Separation schema is open.
The pinned unary L AST is unchanged.

## Syntax-directed finite program proof

The finite_witnesses.mjs compiler mode accepts a pure set-language AST
with distinguished variable at free index zero and finitely many
parameters. Allocate one coordinate for each free variable and one
additional coordinate per active quantifier depth, reusing a slot only
outside its binding scope. Lower the formula to a topologically ordered
list of the five relation operations already in the pinned Def formula:
atomic equality, atomic membership, relative complement, intersection
and existential projection. Falsity is complement of coordinate-zero
self-equality. Disjunction and implication are expressed using
complement/intersection; universal quantification is complement of an
existential projection of the complemented body.

The proof builder constructs actual finite ordinals, tuple graphs and
relation sets, using the existing ZF existence lemmas. Each instruction
has two checked invariant proofs: membership in its relation implies
the exact tuple predicate, and for every tuple and all its specified
coordinate values, relation membership is equivalent to the
instruction's formula semantics. Atomic instructions use functionality
to identify the values; complement and intersection apply previous
equivalences. For projection, extract a witness tuple from the
relation, use agreement outside the bound coordinate and recover
its remaining value by graph totality. In the other direction,
construct the tuple with the altered coordinate using the finite graph
append theorem. All these are proof constructions in the object
calculus.

A separate structural proof bridges the original bounded-to-A
formula and its lowered semantics, including Boolean connectives
and both quantifiers. The base tuple contains the parameters and
a filler element of A; unused coordinates are harmless by the
structural proof. The exact slice characterization follows from
relation semantics and the pinned agreement predicate. When A is
empty and no parameters are required, the given subset is empty,
so use the existing first branch of Def. All other cases have an
available filler by hypothesis or existential elimination.

The checked theorem for each fixed input formula phi(x,ps) is:
  forall A and parameters ps in A, forall b,
    (forall x, x in b iff x in A and phi restricted to A) ->
    D(A,b).
The proof supplies witnesses of the exact pinned program and slice
formulas. This is host-level syntax recursion producing object proofs.
The runtime caps are 0..3 parameters, 6 coordinates and 16 instructions.
The checked examples cover 0..1 parameters directly and up to 2
parameters when the separating set is inserted as an extra parameter.
There is no claim of uniform internal satisfaction or unrestricted
schema coverage.

## Bounded absoluteness

bounded_absoluteness.mjs recognizes quantifier patterns
  exists x (x in y and phi)
  forall x (x in y -> phi)
where y is an existing variable (not the newly bound variable), with
a recursively bounded body. Under Trans(A), A subset L and all free
variables in A, it constructs a logic-only proof of equivalence
between truth restricted to A and truth restricted to L. Transitivity
of A supplies all witnesses of membership in y, and A subset L
supplies the class guard in the other direction. Atomic and Boolean
cases use structural proof recursion. Unbounded quantifiers are
explicitly rejected. Five independently checked fixtures include
nested bounded quantifiers.

## Exact Separation certificates

For each checked formula with zero or one original parameter, start
with a constructible set s and constructible parameters. Use the
existing common-stage proof to obtain a transitive stage A
containing s and the parameter (or s twice in the parameter-free
case). All elements of A satisfy L. Ambient Separation on s,
with phi relativized to the pinned L formula, yields b. For any
x in b, transitivity puts x in A and bounded absoluteness transfers
its truth to A. Conversely, x in A, x in s and the local formula
imply membership in b. Thus b satisfies the exact slice condition
for x in s and phi. Insert the extra parameter s hygienically
into the compiler input; its proof shows D(A,b). The successor
stage definability theorem yields L(b).

The resulting pure closed formula is independently compared against
the guard expansion of the exact relativized source Separation axiom,
generated by the existing axiom policy. Guard conversion and the
ZFC-to-ZF compiler check and import each certificate. No extra
axiom policy, proof inference rule or assumed choice instance is
introduced.

## ACE-03P gate

Generalize the common-stage construction to arbitrary finite parameter
lists, and lift or explicitly manage the compiler/arity caps. Combine
the new definability compiler with the ACE-03N reflection chain for
unbounded quantified formulas. Discharge the one-step bound for
each extracted witness clause, use modular linked proofs if the
expanded trees exceed resources, then verify genuinely unbounded
Separation instances. Only after a general fixed-formula proof
generation argument should we claim the unrestricted metatheoretic
schema. Replacement, Choice, uniform textbook adequacy, formal
checker soundness, native Lean translation and RH remain open.

Seven fixed axiom families are already certified; Separation now has
four checked instances. No paid compute was used in the authoring
runtime.
