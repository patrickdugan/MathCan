# Exact packed indexing and deferred residual reconstruction

ALG-DESCENT-17 companion; paper argument, no Lean verification. In the synthetic Horn domain n<=18, the initial low three bits are always known. The projection k=s>>3 is injective on valid proved sets and fits 15 bits. At most 2^15 distinct valid states exist. Assign each first-seen state an immutable zero-based ID j; encode (k,j) by word w=(k<<16)|(j+1), using 0 for empty. Since j+1<=32768, all words fit uint32, all occupied words are nonzero, and extracting the high 16 bits and low 16 bits minus one is inverse on valid entries.

Use exact key equality, open addressing with linear probing, power-of-two capacity and growth before occupancy exceeds .7. With no deletion, an unsuccessful lookup terminates at the first empty slot: an inserted key cannot lie after an empty slot in its own probe sequence. Rehash reinserts every occupied word under the new modulus; it changes slot locations but not the key-to-ID map. Stable node IDs and independent insertion serials preserve deterministic search tie-breaking. These are logical invariants, not claims about hostile input or overflow outside the stated domain.

For any state S, original hmax distances d_0(S) and initial residual vector a_0 are deterministic functions of immutable rule costs and known facts. An eager residual record at admission stores (a_0,d_0,0). A deferred record stores the scalar hmax, and when selected for first refinement reconstructs the exact same (a_0,d_0,0). Subsequent cut rounds are deterministic and state-local. Therefore the same certified prefix sequence and resulting search priorities are obtained, including if the state is reopened with lower g, provided retained refined state is keyed exactly and never mistaken for an unrefined state. This saves retained records for states never refined but repeats coarse computation for those that are. For eviction of partially refined records, a verified cut history suffices to reconstruct residual costs; recompute residual distances before further refinement. Retain the last certified scalar for unresolved OPEN or conservatively lower it and rekey; never discard unresolved coverage or prune using unverified reconstruction.

Direct incidence boundary union and memoized union compute equal exact rule sets. Replacing the memo table with direct computation therefore preserves the threshold, charge, residual vector and lower bound by induction. Together these representation changes preserve the entire deterministic search trace with identical admission/priority rules and complete frontier. They do not preserve timing or allocation, and their benefit must be measured.
