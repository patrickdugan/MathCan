# IBM Quantum agent prompt: AHR-01

Build and stage a reproducible, cost-capped IBM Quantum hardware experiment for the **Arithmetic Holonomy Rotor (AHR-01)**. Read `AHR01_math_note.md` and run `ahr01_exact_validation.py` first. This is an exploratory 2-qubit gauge-interference experiment; do not describe it as an RH test, a computational speedup, or a consciousness demonstration.

**Mathematical specification.** Use `x=q0`, `y=q1`, and the arithmetic basis `n=2**x * 3**y`. With `N_x=(I-Z_x)/2`, `N_y=(I-Z_y)/2`, set `a=ln(2)`, `b=ln(3)`, `J=1`, `hbar=1`:

`H_phi = a*N_x + b*N_y + J*X_x + J*(I-N_x)*X_y + J*N_x*(cos(phi)*X_y + sin(phi)*Y_y)`.

The `phi` edge is the `10 <-> 11` transition. Remove the global scalar `(a+b)/2` for gate synthesis. In Qiskit Pauli string ordering, mapping `x=q0`, `y=q1`, the seven terms are `IZ: -a/2`, `ZI: -b/2`, `IX: J`, `XI: J*(1+cos(phi))/2`, `XZ: J*(1-cos(phi))/2`, `YI: J*sin(phi)/2`, `YZ: -J*sin(phi)/2`. Validate the Pauli decomposition against the explicit 4x4 matrix under Qiskit's little-endian convention.

**Preflight (local, free).** Pin the installed Qiskit, qiskit-aer, qiskit-ibm-runtime and Python versions. On Qiskit IBM Runtime 0.52.0+, use `from qiskit_ibm_runtime import Sampler` (client-side implementation); verify imports against the currently installed API. Build exact statevector and density-matrix references and Aer noisy predictions; implement 2nd-order Suzuki–Trotter or an exact 2-qubit synthesis and compare circuit amplitudes against `scipy.linalg.expm` before any submission. Test `phi in [0, pi/2, pi]`, `t in [0.4, 0.8, 1.0, 1.2, 1.6]`. Evaluate at least 2, 4 and 8 Suzuki steps, retaining the lowest-depth circuit that meets a predeclared ideal-simulation absolute probability error target `<=0.015` per arm. Flag points that require excessive 2-qubit depth or cannot meet the gate budget. Transpile to a physically adjacent, low-error 2-qubit pair on the chosen backend with `generate_preset_pass_manager`. Preserve backend name, target calibration timestamp (when available), physical layout, transpiler seed, ISA gates, Trotter count, depth and 2-qubit gate count. If an exact 2-qubit compiler beats Trotter in depth with verified equivalence, prefer it and report the comparison.

**Main observable and checks.** Initialize `|00>`, measure computational basis counts. Primary endpoint is `DeltaP(t)=P_00(phi=pi,t)-P_00(phi=0,t)`. At `t=1.6`, the ideal values are `P_00(0)=0.033830` and `P_00(pi)=0.543163`; ideal `DeltaP≈+0.50933`. At `t=0.8`, `DeltaP≈-0.03945`. Show a full curve, binomial 95% uncertainty, exact simulation, transpiled ideal simulation, noisy simulation and hardware observations. Verify the zero-flux closed-form product result. Include a positive phase `pi/2` to exercise complex hopping and, if budget allows, a `-pi/2` reversal symmetry check. The `pi` arm measures flux-induced interference; as a real-hopping sign pattern, `pi` itself does not establish time-reversal-breaking chiral current.

**Critical null controls.** (A) Remove the `01 <-> 11` horizontal edge, creating a tree. For each phi, the return probability must be flux-independent in exact simulation, because phases can be gauged away on a tree. Run a matched phi=0 vs pi comparison on the actual QPU to detect implementation-dependent false flux signals. (B) At phi=0, the Hamiltonian is a tensor sum; its ideal evolution generates zero entanglement from `|00>`. If runtime permits, perform 2-qubit state tomography at `t=0.8` for phi=0 and phi=pi using 9 local Pauli-basis settings. Use mixed-state concurrence or another valid entanglement witness computed from a physical density-matrix estimate, with confidence intervals; do not apply the pure-state formula to raw noisy states. The ideal pure-state concurrence at pi,t=0.8 is about `0.77218`.

Propose an initial small batch (~15 primary circuits + 2 tree controls, up to 2,048 shots each) and a separate optional tomography batch. Estimate usage from backend/runtime metadata where supported. **Verification.** Add unit tests for: Hermiticity; arithmetic discrete curvature `log(6)-log(2)-log(3)=0`; absence of entanglement at zero flux; short-time concurrence `2J^2 t^2 |sin(phi/2)|`; return-probability difference `(J^4/6)(cos(phi)-1)t^4 + O(t^6)`; exact characteristic polynomial shift `2J^4(1-cos(phi))`; tree flux invariance; Qiskit/NumPy basis ordering; Trotter convergence; measurement bit-order parsing.
