## Model and action semantics
Each branch has independent six-valued hidden state with prior integer weights 1..12. State 0,1,2 respectively admits one successful terminal probe; 3..5 admits none. Each branch has 1–3 required sequential sensors before probes unlock. Sensor j observes a noisy public predicate (j=0 parity, j=1 state<3, j=2 state mod 3==0), accuracy drawn independently from {60,80,100}% (noise independent conditional on hidden state). Pay one call per reveal/probe; failed probe excludes its state; stop on success. Priors, sensor types/accuracies and stage counts public. Exact posterior weights computed by integer Bayes updates and gcd normalization. No hidden-state input, no future sensor outcomes. A branch is active once started, until abandoned or no remaining feasible state. Pending active capacity cap=1/2. Opening a new branch when full must abandon one active branch irrevocably; all eviction choices are legal explicit actions. A reveal is legal only with enough remaining calls for that branch's remaining sensors plus one probe. Active exhausted branches free slots. Candidate support masks maintained in every policy (including no-feedback), no probes repeated. Every transition consumes one unit of budget. This is a synthetic exact finite decision model, not a proof verifier. Independent branches mean discarded evidence has no effect on others.

## Controls and features
Depth/probe-first: prioritize available terminal probes, high action ID ties. No-feedback: probe-first using original prior probabilities, reveal by prior best. Marginal: probe-first using posterior; reveal by current max feasible probability. Sensor-aware: score probe by immediate posterior; reveal by expected best candidate probability after one sensor divided by number of sensors still needed before reveal, choose highest; evict lowest current feasible mass (subtract .01 times that mass in reveal tie/score). Local lookahead: score by exact single-branch action success within the global remaining budget (one-branch DP), subtract evicted branch's local optimal value times .25; no cross-branch lookahead. Rollout: at each action evaluate one-step Q followed by fixed sensor-aware policy until budget exhaustion, use best; charge all rollout state/transitions separately, this is a computationally stronger reference. All action-ID ties descending. Marginal and no-feedback choose eviction by lowest current/original feasible mass respectively. Random-eviction control uses the sensor-aware chosen action ignoring its eviction choice then selects a deterministic seeded random legal victim (root seed, public state hash, budget; no hidden value). Exact optimum is reference, not a matched inference-work policy.
