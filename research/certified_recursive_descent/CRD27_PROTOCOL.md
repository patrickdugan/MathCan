## Exact kernels
All new variants retain scalar FIFO, complete descriptor keys, CRD-26 joint top1/top2 sweep and identity omission, with frozen support tolerance 1e-15. Fused uses ordinary sparse DP after neutral omission and single-factor shortcut. Last uses same but only computes final budget in last factor; all earlier factors produce all r=0..b. Linear uses Last plus single/two-factor affordability gate: track three smallest retained positive costs, n positive branches, K=sum_i k_i, J=sum_i k_i^2, candidate count for ordinary fold accumulated as sum_i sum_t(b-t+1). Charge branch and option scans; count same final-factor adjustment in terminal fold estimate. Find minima via fixed comparisons/updates per branch, charge scan once; pair bound n+n(n-1)/2+K^2-J. On single-factor cardinality certificate (sum two cheapest>b) use max single. If sum three cheapest>b (missing infinity), admit direct pairs only if pair upper count plus all gate-estimate charges <= terminal-fold candidate count. Else terminal fold. All arithmetic and pair checks charged. Table uses identical linear gate but selects top-two distinct-branch table when its deterministic charged-work upper count is smaller than pair bound and fits fold count after gate cost. Build per-budget top two failure values and branch IDs using each branch's monotone option cursor, one scan per branch/budget; tie smaller branch index. At most one entry from each branch. Include neutral no-branch fallback 1. For every positive option on i, multiply its failure by best available other branch at remaining budget (second best if first is i). Min over these and neutral. This is exact when at most two positive branches can fit. Use full table independent of gate in unit audits to exercise exact equivalence. Table upper estimate charge n*(b+1) per-cell rangeOutcome, up to total positive options cursor advances charged option, and one allocation per option, plus nodeInit per budget record (three slots: first/second failure + their IDs actually four slots, use four); charge per candidate pair selection, include all setup. Implement simple fixed four-field table, no persisted vectors. If table gate rejects use direct pairs only when cheaper; otherwise terminal fold. No gate based on oracle. Fused, Last, Linear, Table differ only allocation kernel. Use exact same cached leaf arithmetic and bound semantics. Numerical double tolerances inherited, not outward rounded.
