## Arms and common budgets
FullDeadline and FullLazy use unchanged CRD-18 full-refresh Planner. IncDeadline and IncLazy use cached action ranges, reverse dependencies, incremental propagation, same upper initialization and lazy escalation as corresponding full arms. IncCheap uses IncDeadline plus an inexpensive complete root ranking before expensive allocation. IncAdaptive uses IncCheap plus one lazy warm upper backup on a selected unresolved leaf only if its current width >= .10 and estimated remaining affordable branch count>=2, otherwise expand; warm outcomes retained. This is a fixed heuristic, not an optimal computation allocator. ## Incremental correctness
A cached action interval is a weighted sum of child bounds when computed. Child lower increases and upper decreases preserve validity of stale parent intervals. Recompute only affected actions and parent bounds; if a parent's value interval unchanged, do not propagate further. Stage updates in an atomic transaction, including new action list and reverse links; on quota failure discard staged updates, keep previous valid completed snapshot (newly initialized unattached nodes may remain, never appear in retained reachable graph). Charge traversal for every staged node and dependency edge, rangeEval/rangeOutcome for every recomputed range, backup for parent max, lookup/rangeEval for cached range reads, and traverseEdge for reverse link insertion. Copy reachable graph to each possible observed child independently with cached range and reverse links; charge copied nodes and edges and added reverse links. No sibling warming. Counterfactual evaluation may not share refinement beyond the parent's observed path. Audit reached action intervals, exact chosen regret and expected cumulative gap vs oracle. On first two roots per cohort additionally check every completed incremental transaction's cached action ranges against direct full sum and backed node interval containment (audit excluded from proxy). Report action/range evaluations, propagation, lookup, copy costs, graph peaks and utility. Full/incremental policies not required to choose same decisions under finite work quotas because cost differs. Unlimited equivalence audit at root (first four roots per cohort, deadline and lazy each) uses same tie rule, compares final selected oracle regret and full/incremental value within tolerance; use unbounded meter only for audit, no deployment claims. 

## Cheap action ranking
For successor state s' with remaining b', choose one affordable live branch and ignore all future sensor information. Its success lower is TopSum_min(3,b'-m_i)(posterior feasible masses); max over branches is a feasible continuation lower (active eviction allowed for that one chosen branch). Use original prophet upper or exact zero if no affordable branch. For each root action calculate immediate success plus weighted child cheap lower/upper. Charge action/outcome generation, range aggregation, each branch option considered and top-mass evaluation as localMiss. Complete root ranking becomes safe snapshot before costly F allocation; if aborted before completion use same probe-first fallback. In IncCheap/Adaptive, proceed to full graph with remaining quota and choose best completed ranking by largest selected action lower (tie descending ID); if graph ranking lower >= cheap best choose graph; either snapshot valid. In Metered2 evaluate all legal root H2 actions using metered F and one-step memo, retain complete H2 ranking only if complete, otherwise retain cheap snapshot; H2 upper from cheap snapshot, choose best lower snapshot. No actual model calls beyond known conditional transition law.
