## 1. Computation-ordering objective
The finite synthetic independent-branch model uses mandatory sensors, disjoint terminal success events, unit environment action costs and irreversible eviction. Preserve CRD-19's cheap complete action bounds. Let current best action lower be B, and let each unfinished action have valid upper U_a. Any improvement of the best lower from completing action a is at most max(0,U_a-B). The implemented ratio is that optimistic opportunity divided by an estimate of the work needed to compute the two-step action lower. This is a heuristic, not a theorem of optimal work allocation or an estimator of actual utility improvement. All order scores fixed from the initial cheap snapshot. Three orders are descending cheap action lower, descending upper gap, descending upper-gap / estimated cost, with deterministic descending action-ID ties after numerical score quantization.

For a first-successor state with budget b_s, the cost proxy counts each legal continuation action and uses 1+sum over affordable branches of [4 b_s+3 m_i 2^m_i], m_i remaining sensors. This approximates sparse static allocation and likelihood multiplication cost at the next budget b_s-1. Charge the cost-estimation scans and ordering comparisons. The estimate does not model reuse across successor states, eviction, or exact cost of the conditional allocation tables, and is not an upper bound on actual computation. On each completed root action compute the full two-step lower using H1 with exact sparse F. Take its maximum with prior cheap lower. All unfinished action bounds remain valid; skip strictly dominated actions or stop on the numerical regret certificate. If work expires, retain the last complete root ranking, else use common fallback if cheap ranking itself could not complete. Every committed lower is an achievable finite-model value, and each upper bounds optimal action value under the assumptions. Real-arithmetic enclosures require only admissible lower/upper values and monotone weighted sums; JS uses floating tolerances and clipping.

## 2. Memory ablation
All new modes share exact deterministic values for local formula L, static allocation A and one-step lower H in a single namespace-prefixed cache. 8/32/128 slots, each with float64 value and float64 timestamp, so 128/512/2048 bytes of fixed typed numeric payload per cache. JS key/index metadata, array objects, public model, allocation DP temporaries and evaluator stack excluded. FIFO uses a circular slot index; LRU implementation scans all occupied timestamps on eviction and charges those comparisons, as well as touch operations. Both allocate the same numeric arrays. The current LRU is a deliberately simple linear scan; results do not establish the relative merits of O(1) linked-list LRU. Charge writes and eviction before mutating. Reset cache on each decision for fresh arms. Persistent32 clones every occupied entry and timestamps for each possible observed successor separately, charges copyNode and copyEdge per entry, discards the copy if the remaining path cannot pay. The child then constructs its own working cache from the retained copy; this implementation's JS allocation and constructor overhead is outside the proxy. No future outcomes or sibling histories shared. No claim of total RAM cap, actual RSS or physical time benefit.

## 6. Next registered experiment recommendation (not yet executed)
CRD-23 should address the five-branch degradation rather than tune another three-branch ordering. Compare a capacity-aware incremental planner against a streaming hybrid that computes cheap action bounds then refines a small number of promising H2 actions before handing remaining work to incremental Bellman expansion. Include constant-cost ordering and gap-only order, a bounded metadata-aware O(1) LRU or segmented deterministic cache, and selective carryover of only reachable/reusable value keys with copy costs. Use fresh development seeds for fitting any cost/gain prediction and disjoint frozen test seeds with 3/5/7 branch populations; retain exact oracle wherever feasible and explicit interval certificates elsewhere. Measure proxy work separately from controlled standalone Node/Rust time and RSS if the execution environment permits. Do not claim that the current synthetic independent-branch model validates real proof search, correlated inference, full BPD/TRM integration or the original Cogentic factoring theorem. Lean verification and original proof audit remain separate outstanding work.
