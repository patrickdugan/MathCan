## 1. Exact exchangeability quotient
A continuation descriptor comprises unopened/active status, normalized six-state integer posterior weights, ordered remaining public sensor predicates/accuracies. A dead branch has one inert descriptor. Stage-dependent predicates are included through min(stage+j,2), matching frozen fixture law. Two global states with the same multiset of complete descriptors and same remaining budget and capacity admit a bijection matching branches. Legal reveal/probe actions and eviction victim choices map under that bijection; conditional outcome probabilities and terminal rewards agree. By induction on remaining action budget, optimal values agree and action Q tables are equivariant. This only requires matching complete continuation laws, not equal original priors or identical past histories. Independence and the precise abandonment/observation semantics are essential. The implementation sorts descriptors and records inverse slot maps. On duplicate descriptors, stable index order selects a bijection; all value-equivalent permutations yield the same Q for corresponding action orbits. Cache Q by (canonical branch slot, action type, canonical victim slot), then map back to original labels. Optimal value equivalence does not require reproducing the original label-dependent choice among tied actions. This quotient is used in the exact solver audit and sparse allocation memo, not inside the persistent indexed DAG.

## 2. Sparse min-product convolution
For local state with m mandatory sensors remaining, success is zero for t<=m. After sensors, additional probes beyond three cannot increase utility. Thus retain options cost zero and m+k for k=1,2,3 if affordable. If an option's value is at most a cheaper option's value, remove it: replacing it preserves feasibility and weakly improves objective 1-product_i(1-V_i(t_i)). For options numerically equal within 1e-15, implementation discards the larger cost; all checks tolerate 1e-10. Use the canonical multiset key for value-only static allocation cache and share local V by complete descriptor and cost. Convolution evaluates at most four choices per DP cell, so O(n b) combinations after local values computed, compared to dense O(n b^2). This is a bound on combination count, not total time including descriptor sorting and formula evaluation. No witness mapping needed for this value-only allocation memo. 1,296 root/all-budget and 10,587 queried sparse vs dense value comparisons, max error 1.11e-16. All 352 fresh-dense vs fresh-sparse exact action-tree digest comparisons (two per root) match, zero utility discrepancies. Digest is a complete deterministic parenthesized action/outcome tree encoding, not a probabilistic hash.

## 3. Path-specific persistent refinement
CRD-15 Bellman lower/upper envelopes, exact shortcuts and optimistic-gap expansion priority unchanged. Total planning expansions per realized trajectory constrained to 16 or 48; at remaining environment budget b and total planning remainder R, per-decision quota min(16,R-(b-1)). Reserve one root expansion per remaining possible decision. Already expanded root costs zero new expansions. Upon observed nonsuccess transition, re-root to its cached child, copy only reachable descendant DAG and rebuild parent reverse links. All subsequent updates apply within that observed history. Every counterfactual outcome is evaluated with a separate copy of its induced subgraph; no sibling warm start. Fresh planners discard their graph each action. All reset local formula/allocation value memo per decision; interned public local belief tables and fixtures persist, not a physical allocator cap. Expected work measured by finite-model trajectory probabilities; independent evaluator's many counterfactual visits are reported separately. Max expansions on any realized trajectory <= ceiling. Copy counts for retained nodes/outcome edges are charged as separate work, including actual code's deep copy; total work cannot be inferred by subtracting only allocation counts. Peak retained DAG entries count logical cached nodes, not simultaneous evaluator stack copies, other memo arrays, strings or RSS. Planner's Bellman DAG itself remains indexed; canonicalizing the persistent DAG with action remapping remains future work. No learned proposal or training in this experiment.

## 5. Expected regret certificate
For policy pi in the finite decision problem and chosen-action numerical interval gap g_t=max_a U_a-L_selected, the actual one-step regret V*-Q* is <=g_t. Conditional expected regret telescopes by the CRD-11 performance-difference identity even for a history-dependent planning policy:
    V*(s0,B)-V^pi(s0,B)=E_pi sum_t [V*(S_t,b_t)-Q*(S_t,A_t,b_t)]
                             <= E_pi sum_t g_t.
The evaluator explicitly accumulates both the actual oracle advantage losses and recorded gap upper bounds with exact model transition probabilities (double arithmetic). All root-policy evaluations pass telescoping and regret-bound checks. The upper bound is loose: standard persistent48 expected gap sum .213394 vs actual regret .006386; fresh48 .300933 vs actual .006624. Deeper persistent48 .318054 vs actual .006043. These are probability-unit sums, not calibrated prediction of realized regret. A decision with exact tie can be optimal and remain uncertified if competitors have unresolved optimistic bounds. The numerical certificate uses 1e-10 and audit 1e-9 tolerance, not rigorous outward-rounded interval arithmetic.

## CRD-17 proposal (unregistered)
Tighten the prophet upper envelope using a tractable information relaxation. One option: give the controller the true hidden branch state immediately after paying its first remaining sensor action, while still requiring subsequent mandatory sensor costs before terminal probing. Preserve actual eviction rules or explicitly relax them; allow ignoring the extra information so the original policy class embeds in the relaxed policy class. Exact DP for this relaxed continuation model supplies an admissible optimistic bound; validate against the true oracle and count relaxation computation. Compare with simple prophet and one/two-step lower-bound initialization under matched total work, including costs of bounds, and test weighted gap-based expansion selection. Investigate a cheap approximation to the relaxed oracle only when a valid upper envelope survives. Persistent canonical DAG compression should use reversible action/victim remapping, unlike current indexed DAG. Add a fixed cache byte arena and controlled local CPU/RSS benchmark separately. Do not extrapolate to correlated branches or factoring; the original Cogentic theorem remains unaudited.
