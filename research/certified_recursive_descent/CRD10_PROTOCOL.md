## B. Small adaptive information oracle
Separate 192 synthetic decision roots seeds 1650001..1650192. Two independent hidden branches, each state 0..5, prior weights integer 1..12 drawn iid then normalized. Three candidate probes per branch, success iff hidden state equals candidate index 0,1,2; states 3..5 are infeasible. No probes available until paying one call to expand that branch; expansion reveals binary noisy parity sensor (observed bit = state mod2 with accuracy randomly selected from .60,.80,1), and unlocks its three probes. Probe costs one, failure excludes that state; stop at any success. No hidden values in policy. For budgets 2/3/4/5 compute exact optimal adaptive expected success by memoized Bellman recursion over expanded flags, normalized posterior weights, available candidates and remaining calls, considering both sensor outcomes and probe failure/success. Evaluate fixed heuristic policies by the same expectation recursion (not simulated binary outcomes). Controls: depth/probe-first (if unlocked probes choose highest node index, else expand branch index high); marginal probe-first (highest conditional success probe, if none expand largest max prior candidate); sensor-aware one-step (score expansion by expected best immediate probe after sensor, compare to available probe; expansion unavailable with <=1 call); exact optimal. All ties deterministic descending action ID; no future outcome use. Also no-feedback marginal policy ranks using original priors for probe scores even after sensor/failure, while exact evaluation tracks actual observations. Record mean expected utility, regret, number of roots oracle first action differs from marginal/sensor-aware, count optimal choices to expand despite available probes among reachable DP states, DP state counts; verify analytic identities for hand fixtures and monotonic optimal value in budget. This task models genuine information acquisition and branch revelation costs; no claim its optimal policy is applicable to unrestricted trees.
