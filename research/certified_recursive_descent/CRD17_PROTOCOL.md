## Information relaxation and deadline DP
At any observed state with b calls, independent branch beliefs and m_i remaining mandatory sensors. Relax active capacity and irreversible abandonment (allow free preemption). If m_i>0, the first future sensor call reveals the true hidden state, in addition to the original observation; still charge remaining m_i-1 mandatory sensors and one terminal probe to obtain success. If m_i=0 keep actual terminal probe uncertainty; do not grant free knowledge of an already-ready branch. Original policies embed by ignoring extra information, so the relaxed optimum is an upper bound. A branch requiring more than b calls to complete cannot succeed. Screen unready branch i only if at least m_i+1 calls remain; on revealed feasibility, immediately finish it for certain success within budget, on infeasibility discard it. Other observations within a screened infeasible branch have no predictive relevance to other independent branches. Thus a deterministic relaxed policy reduces to its all-failure sequence of screens (cost 1, deadline b-m_i in 1-based position) and ready probes (cost 1, common deadline b). Move screens ahead of probes and order screens by nondecreasing deadline (exchange argument); any feasible all-failure sequence can be reordered without changing its selected success event. Selected ready probes within each ready branch are mutually exclusive and top t masses optimal for t probes. Minimize product of branch failures: process screen branches in increasing deadline, DP by number of actions spent, skip or select screen if next position<=deadline; selecting multiplies by (1-mass_i). Then convolve ready-branch options t=0..3 at costs t with failure 1-topSum_t(p_i). Min over total spent<=b. Complexity O(n log n+n b) arithmetic/combinations for three feasible terminal states; original prophet upper ignores deadlines and probe costs and is always >= relaxation. Exact shortcut for zero/one affordable or all ready unchanged from CRD-15; deadline value itself still a valid upper for every state.

Audit independent relaxed Bellman recursion (screen or actual ready probe, deterministic failure-only continuation) on fresh root states for all b=0..B and all positive-b nonterminal labeled-oracle memo states on first two roots per cohort (or first 128 states in fixed insertion order if greater). Compare deadline DP to this reference and to actual oracle V. Also audit deadline DP vs exact BigInt rational enumeration of screen subsets and ready probe counts on those states. Use floating production DP; numerical comparisons tolerance 1e-10, no outward-rounding claim. Explicitly include hand examples where all screens can fit, tight deadlines prevent testing all screens, ready probes compete, and mixed screen/probe order. Record root and reached-state upper widths and strictly improved upper rates, not only utility.
