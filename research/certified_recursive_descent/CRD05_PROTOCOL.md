## Regimes and observation intervention
New typed layered DAGs use the CRD-02 layer/width/outdegree/depth families and CRD-01 arithmetic certificates. Give every node an independent Bernoulli(.5) latent productive type, then set the randomly planted path to productive. Start is productive. Force its planted edges valid. Other candidate edges are valid with probability .80 (productive source to productive destination), .65 (productive to unproductive), .08 (unproductive to productive), .12 (unproductive to unproductive). This deliberately supplies a learnable signal, not an integer-factorization model. Each node emits a noisy binary relation tag independently conditional on latent type, agreeing with it with probability .85. No latent types or goal identity exposed to policy. The tag is revealed only when an edge to a destination verifies; start tag is known. All node IDs excluded from learned features. Scrambled observation control permutes the tags independently within each layer, preserving the graph, exact certificates, goal, per-layer tag histogram, and teacher outcomes. The original CRD-02 generator, with independent fair tags, is a negative/control regime. Latent variables are generation-only, not available to policy. No claims about true number-theoretic observability.

For each candidate, force retention and expansion, filling other bank slots by depth/random. Run two continuations (random tie keys fixed by node ID and common draw seed, shared across forced actions; no node ID input to model). Exact replay each completed teacher trace including its prefix. Label Q=mean binary success; pair target (1+Q_i-Q_j)/2. Include every pair, orient in current bank order and symmetrize by adding reversed pair; ties have weight .25, non-ties weight 1. Report ties, disagreement and same-observation-signature disagreement. Also measure tag ordering accuracy on pairs with differing Q and differing tag, with simple binary tag comparator. Labels generated once per typed context; same contexts and labels used for typed and scrambled learners; only observation mapping changes. Original control has separate training contexts.

## Model, ranking vs retention, freeze
Seven features: noisy destination tag, observed first-arrival parent tag, clipped observed valid indegree/4, sibling valid fraction, expanded-layer fraction, clipped age/64, remaining-budget slack (remaining calls minus outdegree times remaining depth, divided by budget). All computed only from observed state and known task depth/width/outdegree. Parent tag stored/retrieved only for an already expanded parent. No hidden graph features. 8-parameter linear logistic and 137-parameter 3-step tied recurrent scorer (CRD-03 architecture). Pair logistic gradient, deterministic 8 epochs, 48 minibatches/epoch, 32 sampled pairs/batch, lr .08; initialization 502/503 and sampling 711. Checkpoints epochs 1/4/8; validation cap4/64, choose by solved count, then realized calls, then earliest epoch, separately by model and regime. Freeze weights before generating held-out roots. Model score is 2*depth+sigmoid(logit) (preserves strict depth). Ranking-only: retain using depth/latest, then rank surviving entries with policy. Joint ranking/retention: same policy for trim and order. Validation uses joint. Controls depth/latest, depth/random ties, tag-only (2*depth+tag), and linear learned. Test typed recurrent joint under true and scrambled tags, independently trained scrambled recurrent joint, and true recurrent ranking-only. For original negative regime, train separate linear/recurrent models and test same controls; no typed-to-original transfer claim.
