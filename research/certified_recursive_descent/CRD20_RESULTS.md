## 1. Partial Bellman lower-envelope invariant
In the frozen independent finite decision model, every legal action a has immediate success mass and nonterminal conditional successors. Let each successor have valid interval [l_j,u_j]. A valid action interval is [p_hit+sum p_j l_j,p_hit+sum p_j u_j]. Replace one successor interval by its intersection with any newly available admissible interval. All parent action lower bounds weakly increase and upper bounds weakly decrease. A full action roster admits a state bound [max_a L_a,max_a U_a]. A partial evaluation retains prior valid bounds for all unfinished terms. The state lower also retains the achievable static allocation F; the upper retains previous prophet/other admissible values. Consequently every committed root ranking is usable under interruption, and its chosen-action regret is bounded by max_a U_a-L_selected. Expected sum of these decision gaps bounds full policy regret by the CRD-11 identity, even for history-dependent computation allocation.

Initial cheap root intervals use CRD-19's best single-branch feasible lower and original prophet upper. The implementation creates a full root action roster and shares indexed first-successor records within each decision. First refine with static F. Second enumerate complete child action rosters, then improve individual nonterminal terms with F. In the weightedDeadline arm also compute deadline upper bounds on second-level terms after their F refinement. Atomic term update charges all affected weighted sums and root-ranking scan before commit. An aborted operation leaves the preceding valid root ranking; unfinished local calculations do not corrupt it. When no initial ranking completes use the common legal probe-first fallback, interval [0,1], gap 1. In exact real arithmetic every completed update preserves enclosure. Production implementation uses floating tolerances, not formal interval arithmetic. Unlimited sequential finishing matches max(cheap,T^2 F) for all audited root actions; this is an attainable lower bound on optimal Q, not necessarily Q itself.

Sequential order uses insertion order (first-successor F phase, then child roster/term phase). Weighted order considers current root competitors with upper >= best lower within tolerance, and prioritizes summed reach probability across those actions times current interval width, including second-level outcome probability. It may omit a child action dominated by the current child lower. This is a heuristic for refinement value; uncertainty magnitude is not equal to decision improvement. Each task selection scans records and charges node/range reads; each committed update recomputes affected root sums and a full ranking. Transposition sharing is confined to indexed first successors and deterministic local/static memo tables; child action tables are reused within a decision. Progressive graph discarded after each observed action, no sibling warm start or persistent cross-decision graph. CRD-19 IncCheap retains its original persistent graph and Metered2 its original no-graph implementation.

## 2. Work and arena
Shared path ceilings 2,000/8,000 units, per-decision allowance min(R,ceil(2R/b)), same public model setup and fallback. Frozen CRD-18/19 weight-one proxy charges allocation, likelihood products, record initialization, bound calls, action/outcome generation, lookups, range reads/sums and task scans; aborts charged. Sorting/string/object overhead and evaluator, oracle, setup and fallback/environment execution excluded. Charged work is not measured FLOPs or time.

The 96/32 logical record arenas bound the admitted per-decision roster: root action, root outcome, distinct first-successor state, second-level action and outcome each count one. A child roster must fit in full before admission; otherwise mark that child blocked and continue other eligible work. All records retained until decision ends, no eviction. Initial temporary root construction and cheap snapshot exist outside arena; atomic staged child/row copies, public pre-intern model, local/static/deadline memo tables and evaluator stack are also outside. Hence this is a hard admitted-record limit, not a numeric-byte arena or physical RAM cap. The actual code does not enforce the limit on temporary staging. Peak records reported only for progressive arms; comparator storage not measured in these units.

## 6. CRD-21 proposal (unregistered)
Replace repeated task scans with a dependency-indexed priority queue and incremental weighted-sum deltas. Maintain cached action sums, root best-lower and competitor upper heaps, and charge heap pushes/pops, dirty-edge updates, and invalidations. Compare against a simpler interrupted per-action H2 evaluator which saves completed whole action bounds without full second-level rosters. Test cheap root snapshot held outside arena versus fixed typed-array numeric arena with actual byte accounting. Keep allocation/likelihood memo bounded and account for it as well. Use fresh roots and fixed proxy/real timing controls. Strong classical Metered2 remains necessary reference. No factorization or ECDLP result follows.
