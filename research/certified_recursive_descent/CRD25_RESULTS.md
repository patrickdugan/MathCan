## 1. Exact Pareto algebra
Use the CRD-14/24 independent-branch static allocation model. For an at-most-budget failure vector f_i(t)=1-V_i(t), retain each strict decrease in failure at increasing cost; (0,1) is implicit. Every discarded point is dominated by a cheaper point with no larger failure. Multiplication of nonnegative probabilities preserves this dominance. To compute f*g at budget r, enumerate pairs of retained points (x,f(x)), (y,g(y)) with x+y<=r and minimize their product. The result equals the minimum over all affordable allocations: any discarded input point can be replaced by a retained point of no greater cost and no larger failure. Collect min product per cost and take prefix minima; retaining strict decreases again yields the exact support. The proof uses at-most budgets and independence. It does not generalize to correlated events without a different joint objective. In exact arithmetic support merging is associative because the underlying min-product convolution is associative. Local leaf support has at most three explicit points (m+1,m+2,m+3), with implicit zero-cost identity; combined support can have B explicit points.

The adaptive implementation chooses between direct pair enumeration and dense expansion of the larger support with one-sided sparse convolution. If k,l include the implicit zero point, compare proxy estimates 2kl and (B+1)min(k,l)+2(B+1); tie chooses pair. These are heuristic upper-count estimates, not an exact minimizer of charged work. Direct pair affordability checks and dense scratch initialization and compaction are charged. Both methods retain strict decreases and use float64 probabilities. Identity factors have empty supports. Neither method has a general measured speed advantage at short horizons. Independent rational integer-numerator unit checks cover both forced algorithms and adaptive selection.

## 2. Joint local likelihood sweep
For a branch with m remaining mandatory sensors, define w_j(u)=p_j Pr(u|j) for the three feasible hidden terminal states j and a full sensor word u. The exact local value with k terminal probes after the sensors is sum_u TopSum_k(w(u)). The one- and two-probe values therefore share identical likelihood multiplications; a sorted feasible-weight triple supplies both top sums. The three-probe value is total feasible mass by summing the full word law. For a single branch, zero or unaffordable allocations give zero utility. The joint variant calculates the one/two-probe outputs needed by the current horizon in one pass, charging output accumulation, local value operations and the shared likelihood products. Ordinary variants use the frozen local calculation separately. This exploits the same mutually exclusive three-terminal-state model as CRD-12; it is not a new bound for arbitrary optional sensing.

## 3. Packed cache and sibling reuse
Modes: frozen Direct unbounded sparse scalar, Scalar bounded scalar, Tree bounded dense-vector tree; PackedFold leaf/root products, PackedTree balanced segments in one arena, SplitTree separated leaf/deadline and product regions, Sibling expansion-local base products, SiblingJoint same with joint leaf sweep. All bounded modes allocate fixed numeric payload 64*(B+1)*8 bytes: 3584 at B6 or 3072 at B5. Packed arena stores Float64 cost/failure pairs (224 or 192 pair slots). For SplitTree/Sibling each region has half the pairs. Empty supports reserve one pair so metadata record counts remain bounded. Leaf keys canonicalize complete continuation descriptors; segment/root keys are indexed within a root. A stored larger horizon may answer a smaller query by truncation; a smaller horizon cannot answer a larger query. FIFO ring tracks physical occupancy; superseded records may remain until their physical eviction. Complete new record is inserted only after paying eviction and coefficient-write charges. Copy read supports out of the ring, so later slot replacement cannot mutate earlier values. Store validation checks ring contiguity, nonoverlap, occupancy and index membership; charges exclude diagnostic validation. Product separation protects leaves but restricts product capacity.

Sibling uses a parent expansion context. For child state s' and current horizon b, let J be the one/two indices whose local IDs differ from parent s. Compute base support product of unchanged factors in s at b, cache by J within this expansion, then merge child factors at J. This is exact by the support algebra and includes victim deletion (identity). If no matching context, fold without caching root products. Clear the product region at beginning of each expansion (charged reset); never read old products outside their scope. Leaf values remain cached during the decision. Actual graph propagation/retention uses frozen Inc19, with context opened around expansion and closed in finally even on abort. No cross-sibling evaluation warming after actual observed decisions, and no persistent new value cache across decisions. All bounded typed payload excludes JS metadata, support/scratch arrays, graph, public model tables, allocation object overhead and evaluator recursion; no total RAM limit. Scalar has more one-number records at equal numeric bytes. Work proxy includes coefficient copy/writes, scratch initialization, allocation candidate evaluation, support scans and metadata lookup/segment operations, but excludes actual JS allocation, sorting and GC overhead. Costs are not measured physical FLOPs or latency.

## 7. CRD-26 proposal (unregistered)
Return to the scalar allocator as strong control and isolate the successful joint local sweep. Store scalar local values keyed by complete descriptor and number of remaining probes; optionally compute top1/top2 together when both are requested, without materializing dense or packed global products. Add affordability-aware scalar convolution: omit all identity branches, restrict local option costs to zero/m+1..m+3, and use the bound floor(b/min_i(m_i+1)) on the number of branches with positive allocations. When at most one or two positive branch allocations can fit, derive exact max/min formulas or enumerate only affordable pairs, and compare charged cost against sparse scalar DP (no pruning that discards viable plans). Distinguish lazily computed local values from precomputed all-budget lookup, test bounded scalar cache with shared numeric payload and fixed work, include the strong original IncCheap and Metered2. Use fresh roots, include actual evictions and exact all-budget coefficient tests. A work-calibrated H2 gate and learned allocator remain deferred until simple exact local and global arithmetic is affordable. Standalone Node/Rust and controlled physical memory profiling are separate tasks; original Cogentic proof audit remains outstanding.
