## Action and target
Use CRD-03 verified destination bank, with one active expansion and bounded pending destinations, charge every arithmetic check. At a pre-trim scheduling state S with >=2 candidates and remaining verifier calls, clone the state. Force each candidate e to be retained and expanded next, filling the other cap-1 slots by depth/latest priority. Continue with depth/latest priority under the original remaining budget, preserving already expanded nodes, paths and observed counts. Y(S,e) is the exact binary success of this continuation. Form all unordered candidate pairs, orient deterministically by current bank order. Pair target is 1 if Y_i>Y_j, 0 if Y_i<Y_j, and 0.5 for a tie (including both successes and both failures). Train logistic loss on logit_i-logit_j, no cost tie-break and no static reachability target. Teacher rollouts may access future graph only through the verifier; no outcome/seed/hidden adjacency/goal identity enters features. Count teacher calls separately; do not include them in deployment budgets.

## Freeze
Train roots 710001..710384: first 192 from development generator, next 192 validation generator (distinct roots from all validation/test). Validation 820001..820128 from validation generator; test 930001..930256 from heldout generator. Training behavior depth/latest and deterministic random priority, cap 4/16 (four trajectories/root), budget selected by root index mod 3 from 24/40/64. Uniform deterministic reservoir of up to 3 eligible pre-trim scheduling states per trajectory. All pairs retained, including ties. Exact independent replay of full forced continuation including shared prefix. Model features as CRD-03: relative depth, absolute remaining depth/10, age/64, observed indegree/4, expanded layer fraction, sibling valid fraction, remaining budget fraction. No candidate IDs, graph seed, or offline label features. Both scorers share data. Deterministic SGD: 16 epochs, 64 batches of 32 pairs sampled with replacement per epoch, lr .08; initialization seeds 502/503, minibatch seed 711. Evaluate epochs 1/4/8/16 on validation cap 4, 64 calls with progress-preserving residual; select by solved count, then fewer realized calls, then earliest epoch. Freeze both weights before creating test roots. Primary recurrent residual score is 2*depth+sigmoid(logit), so depth order cannot invert. Unrestricted recurrent uses exactly the same selected weights and sigmoid score. Include linear residual, same-depth random tie priority, depth/latest (primary control), FIFO, unrestricted random, and recurrent unrestricted. Tie-break by latest insertion. Fixed random keys assigned deterministically per insertion, identical generation for every policy and clone; keys never model inputs.

Report paired gains/losses, exact two-sided paired sign test; compare same-depth random and linear residual as controls, unrestricted as ablation. Also record training teacher rollouts/calls, label distribution and disagreement fraction, independent replay of every test trace, false accepts, realized call and score-evaluation counts, peak bank and transient counts. Candidate capacity excludes shared fixture, path storage and observed maps; actual RAM not inferred. No test tuning. Null or negative outcome accepted. Test splits retire afterward.
