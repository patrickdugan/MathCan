## Ordering and shared resource contract
Use frozen metered whole-action H2 lower (two actual Bellman backups of F); retain cheap complete root ranking, commit each complete root-action bound separately. Keep all unfinished root intervals, skip actions with upper strictly below current best lower (tolerance EPS), stop on certificate. Three static orders: cheap lower descending (baseline), upper-gap descending (U_a minus initial best lower, clipped zero), and ratio of upper-gap to estimated work. Ties descending action ID with 1e-12 quantization. Ratio estimates cost using each non-hit first successor's legal action count times a proxy for one static allocation: 1+sum over affordable branches of [4*(b'+1)+2^(remaining sensors)*3*remaining sensors], with b' successor remaining budget minus one in allocation proxy; use actual successor affordability for conservatively estimating magnitude (not a guaranteed operation upper bound). Sum estimated cost across outcomes without probability weighting (all must be evaluated). Add 1 per first outcome and per successor legal action; zero when no legal actions. Charge estimate's action enumeration/branch option scans, lookup and comparison in existing ledger; do not generate second-level outcomes to estimate. Score order fixed after cheap root snapshot; no oracle labels. Upper-gap is an admissible optimistic opportunity bound on improving best lower, not predicted actual gain. Cost estimate deliberately coarse, no trained predictor. Audit cost estimate vs actual charged work of completed action, rank correlation descriptively, record failures and estimate overhead. Unlimited completion (disable dominance/early stop) must match independent dense T^2F on all root actions, including cache-eviction variants.

## Cache study
New whole-action modes cheap128, gap128, ratio128 (fresh FIFO, 128 slots), cheap32 and cheap8 (fresh FIFO), lru32 and lru8 (fresh LRU same cheap ordering), persist32 (LRU cheap ordering carried along observed path), ratio32 (fresh FIFO ratio). Metered2 frozen and IncCheap frozen references on same roots. For all new arms fixed Float64 value and timestamp arrays, capacity C=8/32/128 =>16C bytes; key and index metadata outside numeric payload. One shared namespace for exact local, static and H1 deterministic values. Charge writes, eviction, LRU touch, candidate victim scans, lookup; FIFO direct circular slot, LRU scan for minimum last touch with index tie. Prefer empty slots before eviction. Cache operations charge before mutation; count aborted attempts. Persistent arm copies entire occupied memo into each possible observed successor using separate clone and path budget; copy charges per occupied entry (copyNode and copyEdge), preserve timestamps/order; if cannot pay discard copy. No sibling warming. Stable public local posterior IDs pre-interned, indexed H1 key valid within root, canonical local/static values deterministic. All new arms share same capacity accounting and LRU/FIFO numeric payload. Cache correctness verified against unrestricted values in completion audits and separate small-cap unit checks. No full memory/RSS claim.
