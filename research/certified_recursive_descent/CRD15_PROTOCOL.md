## Bounds and exact shortcuts
For finite independent-branch belief state s and remaining action budget b, lower F(s,b) from CRD-14 static allocation with exact local formula. Upper U(s,b)=1-product_i(1-mass_i) over alive, individually affordable branches (remaining sensors+1<=b). Any success requires a feasible hidden state in such a branch, even if a prophet supplies hidden-state information; ignore capacity, shared actions and abandonment in this relaxation. If zero affordable branches set both zero. If only one affordable branch, exact optimum is its local V(b): another branch cannot become affordable by spending calls on this one or other branches. If all affordable branches already have their mandatory sensors complete, no informative sensor or unopened affordable branch remains, all continuing outcomes are failures; exact static optimum equals adaptive optimum (fixed ordered probe set, no branch opening needed). Use these exact shortcuts in both selective variants; record counts. All arithmetic in finite-model double precision; tolerances are numerical, not formal outward-rounded intervals.

## Planner
Per real decision create a fresh DAG cache keyed by local state IDs and budget, so evaluation of counterfactual siblings cannot affect a policy's planning limit or action. Share only deterministic local formula/static-allocation memo values across policy evaluation states; work counts reflect offline shared memoization, not a per-trajectory deployment latency. Initialize lower/upper lazily on node creation, cache successor edges. Expand root once even if its value bound is exact, so actions can be selected. Expanding a state enumerates every legal action and nonterminal outcome; each expansion costs one planning node and each generated outcome counted separately (hit terminal included). Parent reverse pointers permit monotone updates: intersect original/current node interval with max-action lower/upper backups, propagate changed intervals to all ancestors. Action score lower/upper computed from child intervals. Choose best lower action, tie descending action ID with 1e-12 quantization. Stop if its lower is within 1e-10 of all action uppers; record approximate-optimality certificate and gap max U - L. Otherwise refine one leaf chosen by descending optimistic action upper (ties action ID), then max probability times child interval width (ties deterministic child key); only consider actions with upper > current best lower + tolerance and children with nonzero gap. If a selected optimistic action is exact and dominates then node already resolved; try other overlapping action if no improvable child. Recompute ancestor intervals and repeat until budget. Primary node ceilings 4/16/64 expansions per decision, and unlimited exact-certifying variant. Root expansion counted; no lookahead beyond remaining action budget. When ceiling exhausted select largest action lower (never optimistic-only), report gap. Record exact shortcut counts, node creations, expanded nodes, outcome counts, parent propagation/backups, peak DAG entries, allocation combinations, local formula patterns/cache hits, policy evaluation states, certificate rate and actual regret. Unlimited mode must certify every action up to numerical tolerance; finite modes may stop uncertified. For all reached decisions verify exact oracle action value in [L_a,U_a] for selected action and optimal regret <= recorded gap +1e-9, plus state-value bounds, independently align beliefs by stage/integer weights. Audit after policy work counters frozen.
