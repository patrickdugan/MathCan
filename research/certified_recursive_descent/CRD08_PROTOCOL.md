## Task and data
Hidden group S3 indexed 3*s+k (r rotation, s reflection), right multiply by input token r=(1,0), s=(0,1). At each transition, with probability c replace the state by an independent uniform group element; otherwise apply the token. Terminal output label is a fixed permutation of the six hidden group indices [2,5,1,4,0,3]. Learners see only words of (token,c) and terminal labels, not hidden group indices, intermediate states, group tables, relations, or permutation. Known output alphabet size six. Exact oracle has generator matrices and reset probabilities. Channel family is explicitly supplied to the structured learner; learning the permutation actions is the point, not group discovery without priors.

Balanced training experiment: six anchor prefixes [], r, rr, s, rs, rrs, each prefix token noise c=.10; for each anchor, terminal label samples on the prefix alone or after one token r/s with c=0/.15. 384 independent samples/cell, 30 cells, 11,520 rows. Seeds 1440001 onward in fixed cell order. Anchor words supplied as an experimental design, not labeled group states. Let P be empirical 6x6 prefix output matrix, P_(a,c) after token. Learn unconstrained moments A=P^(-1)P_(a,c), fail if singular. Gauge in prefix coordinates: C=P_(a,c)P^(-1)=P A P^(-1). Use exact row-simplex projection for stochastic baseline, and evaluate at arbitrary c by affine extrapolation of the raw endpoint matrices then projection (raw moments themselves may produce negative probabilities; report raw signed outputs, row-sum errors and relation residuals, not invalid CE). Structured model fits each noiseless permutation separately by maximum total row score over all 6! permutations; estimate one reset mixture coefficient per token/endpoint by least squares from empirical anchor outputs vs P times learned permutation, constrained to [0,1]; linearly interpolate/extrapolate coefficient, clip to [0,1]. No group relator supplied to fit. Initial output state P's empty-word row for all identified operators. Report learned relators r^3, s^2, srs=r^2, generated action orbit, character traces, central idempotents from six independently named words e,r,rr,s,rs,rrs (projector validity must be audited, never assumed), dimensions/traces and defects. Test trace invariance under P similarity. Raw moment model tests approximate relations in fixed observed-output coordinates, not gauge-invariant Frobenius distance.

Validate macro-product equals stepwise composition. Use true conditional posterior as diagnostic, not labels or inference inputs.

## Adaptive branching
Separate fresh roots 1470001..1470192 (192), common depth 5..7, binary tree. Each edge token r/s uniform and channel level c from registered regime, independently generated; hidden child state conditional on actual parent via above law. Root identity, independent uniform terminal target label. Generate fixtures independent of policy with per-edge observed token/noise and valid arithmetic certificate; hidden state unavailable to scorer. Only expanding a reached node reveals its two edges sequentially, each exact verification costs one call; terminal probe costs one call and checks latent target, failed terminal removed. Bank cap 4 or 16 pending nodes; expand/probe next ranked entry, discard overflow. Stop at success, empty bank, or total ceiling 24 or 48. All policies know depth, observed path, target; no future edge symbols or hidden states. Policies: depth/latest, depth/random ties, exact marginal-filter residual, inferred permutation-reset residual, inferred stochastic residual, hard learned composition residual, generic RNN residual. Residual score 2*depth+forecast target probability, using known future iid token and noise-level law (average transition matrix to remaining depth for exact/identified filters; hard uses average noiseless inferred action; generic RNN uses current target readout, no future rollout). All preserve depth, terminal failures do not update other branches' marginal filter: shared prefixes induce dependency, so exact marginal is not a full optimal adaptive Bayes policy. Use identical root trees per regime; shifted states may differ. Count every prefix and terminal check and score; verify successful path independently, no false accepts, report top-choice changes on baseline decisions, retained count, numeric payload only. Compare cap4/24 primary original, cap16/48 and shifted secondary; descriptive paired exact sign test. No budget equality in CPU operations. In addition exact small coupled-candidate counterexample with two identical Bernoulli(.6) branches and independent Bernoulli(.5) branch, k=2: marginal top-k vs diverse set, enumerate four worlds. No independent-top-k theorem applied to correlated tree.
