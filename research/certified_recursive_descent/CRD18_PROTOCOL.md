## Shared work proxy
Compare a new common persistent indexed DAG implementation, with five upper-bound strategies: prophet; eager deadline; eager backed (discard warm transition records); eager backed-reuse (retain warm transition records for later actual expansion); lazy (initial prophet, escalate selected unresolved leaf to deadline, then warm backed upper with reusable transitions, then full expansion if needed). Exact shortcuts and sparse static lower F from CRD-15/16. All use same action ties (1e-12 quantized lower, descending ID), same optimistic action/weighted-child selection. Root expansion required to score actions; root warm computation can occur in eager arms. No learned proposal. Per-trajectory weighted work ceilings 2,000 and 8,000 units; per-decision ceiling min(remaining, ceil(2*remaining/b)). Reserve no minimum for later decisions; if no completed root score within quota, use common deterministic probe-first fallback (highest action ID among probes else all legal). Compute fallback in all arms; its legal-action enumeration and actual environment transition are common overhead excluded from proxy. All planning operations charged before performing them; abort on insufficient remaining units, keep last completed root ranking if available, otherwise fallback. Count work spent in aborted operations; incomplete node/edge lists never attached. Complete valid bounds may survive abort. On fallback report conservative gap 1, otherwise saved interval gap; audit true action regret against it. At each decision after selecting action, persistent graph copy of observed successor reachable nodes/actual and prepared edges costs one per node/edge; abort copying and discard graph if remaining trajectory work cannot pay. Copy work consumes total work (not per-decision planning ceiling). Counterfactual outcomes use separate copies and separate work remainders. Common public pre-intern setup, legal fallback and environment execution, evaluator, oracle and audits excluded from proxy; report setup and work separately. Cache reset per decision except retained node intervals/edges and prepared warm outcomes. No physical time or byte claim.

Charge one unit each for local-value miss, each likelihood multiplication (3*m per sensor word), each static allocation option considered, each allocation candidate combination, each deadline DP call, each screen item sorted (proxy for sorting), each deadline candidate combination, each planning node initialization, each legal action enumerated for warm/expansion, each generated outcome, each leaf-selection node visit, each action-range evaluation (plus one per outcome summed), each backup node visit and each graph traversal/copy node/edge; count canonical/local cache lookups once each. Use one common ledger, no overshoot; operations charge atomically in advance, cache hits charge lookup only. Sorting/string allocation/JS overhead not faithfully measured; this is a deliberately specified weighted arithmetic/work proxy, not FLOPs or CPU time. Can reuse underlying sparse allocation counters by explicit metering implementation; no hidden full allocation or oracle value in planner. Root ranking snapshot uses all legal action intervals and copied numeric values; stale enclosures valid. Recompute reachable graph bottom-up after each completed refinement (including partial work if interrupted); retain valid intervals only, no need for reverse pointers. Reuse CRD-17 exact upper formula; warm bound max of actual one-step deadline successors. Warm transition records reused without regenerating outcomes in reuse/lazy arms, but charge traversal and child initialization. Count all bound, warm, actual expansion, reuse, and abort operations. Peak logical graph node/edge counts not bytes. Audit every reached chosen action against independent exact oracle, every completed root range, expected cumulative gap vs policy regret and max path weighted work. No use of oracle in policy. Report expected utility and expected charged work (probability-weighted), max path work, fallback rates, new expansions, allocation/bound combinations, warm/reused outcomes, copy work, certificate rate, gap, peak nodes. Compare fresh root exact and receding2 nonmatched references. No post-test tuning.

## Capacity-one envelope (separate math audit)
For cap1 and one active branch, screen an unready active branch first or abandon it; a ready active branch may use k actual probes before opening any new branch, after which it is irrevocably abandoned. Remaining unopened branches are pure screens in the relaxation; independent feasibility, deadlines adjusted by cost already spent. Optimize over these prefixes and abandonment, using deadline screen DP for others. Active successful screen ends with certainty after paid completion; on failure continue with other screens. This is the relaxed optimum preserving cap1 abandonment (original policy embeds), <= unrestricted deadline upper. Do not use in main five-arm planner comparison. Verify independent exhaustive recursion on fresh cap1 oracle states, compare bounds vs actual V and unrestricted deadline. No correlated-branch claim.
