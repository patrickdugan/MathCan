# NOR-35: exact within-atom random-reserve and quota-matching mathematics

The prospectively registered [NOR-35 applied study](https://github.com/MoralityLabAI/Compactification-Theory/blob/research/nor35-intraatom-curvature-rerank-20261117/research/nor35_intraatom_curvature/REGISTRATION.md) evaluates new curvature-targeted 16-query audits that change WHICH public output coordinates are inspected within the eight original tail/top-magnitude/lag membership atoms, while holding the exact old NOR25 atom inspection counts fixed for every source, trial and base auditor.

The MathCan/NOR35IntraAtomCurvature.lean module proves two conditional statements. Under a fixed public deterministic targeted prefix within any one atom, a blind attacker alters a fixed set of residual positions before independent uniform reserve coins are drawn. When no attacked coordinate lies in the targeted prefix, the exact number of size-u uniform reserve schedules missing r residual altered coordinates is C(N−r,u) from C(N,u) equally weighted schedules. A targeted prefix hit forces all schedules to detect. Multiplying these counts across independently sampled reserve draws in arbitrary disjoint atom lists gives the exact multi-atom numerator/denominator product, including zero-miss cases.

Separately, if source/trial auditors inspect identical quotas t_j inside the SAME eight source-public atoms, then the exact miss/total counts for a blind attack redrawn uniformly with a fixed atom quota q_j are identical for every member of that audit family. This is the NOR34 fixed quota sufficiency theorem specialized to intra-atom schedule transformations. The total exact witness query charge remains equal. A constructive fully schedule-informed alternative future still has the same checked-value transcript when unchecked coordinates exist.

The applied experiment measures whether publicly estimated curvature inside each atom increases detection of attacks sampled from high-curvature supports, compared with atom-quota-matched uniformly redrawn and inverse-curvature policies. It uses 24 genuinely fresh RRC25 sources, 16 fixed attacks in each of four source-public families and 512 independent audit plans per source/arm. The theory guarantees conditional equality for the atom-quota matched attack law; it does not prove extra curvature detection, independent secure OS entropy, actual source-generalization, or authenticity of the exogenous target coefficient witness. Public hash-based seeds are reproducibility fixtures only.
