## COL-03 design and chronology

The primary rule was written before the first larger-parameter run.
Development contains every d=1 mod 4 coprime to 6 in[5,1025]; evaluation uses
the same filter in[1029,8193]. The size baseline fits log(median period) against
log(unit odd core size) only on development. The lattice rule receives d and
the arithmetic unit count before graph enumeration. Its coefficients are
fixed by the stated2-adic heuristic and are never fitted to target periods.

The outcome is one relative absolute period error per parameter, summarized
by the median. Its target weights every unit cycle equally. The full 1,365-row
CSV retains exact-pair hit counts, zero-triple cycles and every parameter.
Cycle-level aggregates are descriptive; the extrapolation unit is d.

After observing the first result, controls changed the candidate direction
to4 or8 and removed the slope band, retaining A>=2u. All use A+2u to convert
the selected pair to a period. These extra controls are explicitly
exploratory. A later implementation edit moved arithmetic feature computation
ahead of enumeration without changing any predictions. The source manifest
records the current rule and implementation, with no independent timestamp
attestation. This is a public finite extrapolation study.

## COL-03B: freeze a new arithmetic family

Before inspecting further cycles, declare balanced blocks by scale and prime
support. Include factors at which2 is not primitive, and use the general
lattice solver so implementation eligibility does not select the domain.
Keep all present rules. Add a training-only baseline using phi(d), largest
prime factor and the orders of2 and3. Report relative and signed errors,
family coverage, zero-triple rates and full computation cost. Predeclare an
abstention outcome for parameters exceeding the graph or order budgets.

A mathematical continuation should connect short lattice points to legal
closed branch words through the affine offset B and the core inequalities.
The finite results provide evidence for choosing that target.
