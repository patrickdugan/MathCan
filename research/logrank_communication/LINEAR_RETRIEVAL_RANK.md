# Exact static linear retrieval requires full rank

Let x be any vector in {-1,+1}^k. An injective address map selects a row w_i of a real k-by-k matrix W (reorder addresses by coordinate); the reply is 1 iff w_i x + b_i >= 0. For exact recovery of x_i, put S_i=sum_{j!=i}|w_ij|. The worst positive input gives w_ii+b_i-S_i>=0. The worst negative input gives -w_ii+b_i+S_i<0. Thus w_ii>=S_i-b_i and w_ii>S_i+b_i. If b_i<0 the first inequality implies strict dominance, and if b_i>=0 the second does. Hence w_ii>S_i for every i. If Wv=0 for nonzero v, choose i maximizing |v_i|; w_ii|v_i|<=S_i|v_i| is impossible. W is nonsingular and rank(W)=k. In particular any factorization W=VU with intermediate width d requires d>=k. Conversely the identity matrix suffices.

This is a static affine threshold readout theorem over the entire hypercube, with a single response bit and known injective address. It is not a lower bound for nonlinear state transformations, context-conditioned weights, arbitrary decoders or all recurrent architectures. Reordering addresses or flipping the response convention per address preserves the rank conclusion. A strictly positive diagonal-dominance margin certifies exact retrieval without enumerating 2^k memory vectors; numerical certification needs rounding bounds or exact coefficients. A signed coordinate-selection matrix gives an exact integer witness.

## Hierarchical assignment

At a fixed binary prefix, with an even-sized set S and logits l_j, maximizing sum_j log Bernoulli(t_j;sigmoid(l_j)) subject to exactly |S|/2 ones reduces to maximizing sum_j t_j l_j. Sort the logits and select the upper half. Inductively balanced splits produce a bijection between k=2^q queries and q-bit leaves. This is greedy conditional optimization; it need not maximize total path log likelihood. Scoring one assigned path per query costs kq state/head positions, versus k^2 q in the naive full-path enumeration used in LOGRANK-BPD-04. Prefix-cached flat enumeration reduces duplicated positions. Sorting all balanced subgroups costs O(k q^2) comparisons. Written proof, not Lean-checked.
