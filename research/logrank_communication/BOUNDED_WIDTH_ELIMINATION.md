# Certified bounded-width factor elimination

Source and finite checks: https://github.com/MoralityLabAI/LoopedTransformers/tree/029350cdbaeda9ad8abb011ee66d2eddd2c95662/experiments/logrank_bpd_16.

For nonnegative bucket products G_j(x,z), designate anchor j*. Fix z. Each other product is bounded pointwise by its minimum and maximum over x. Hence (sum_x G_anchor) prod_other min_x G_j <= sum_x prod_j G_j <= (sum_x G_anchor) prod_other max_x G_j. Apply to lower and upper factor tables separately; nonnegativity makes multiplication and summation monotone. Replacing each bucket by these new factors inductively gives a lower/upper bound on the full partition sum. With one group per bucket the operation is exact. A maximum scope of c including the eliminated variable bounds each table by 2^c entries, not total memory or integer bit complexity. Exact elimination is possible when the ordering's induced width is at most c-1.

A connected component of variable count k and residual mask rank r can be integrated by enumerating the r independent parity coordinates and multiplying by 2^(k-r). This can be preferable to variable elimination when r is small. Conversely a connected component with full rank k can be easy when elimination width is small. Disjoint components multiply their partition sums.

For a nonzero query mask q, condition on q dot h=b by eliminating a pivot coordinate i in q. Every row a involving i becomes a XOR q and observed parity y becomes y XOR b. The remaining variables parametrize the event bijectively. If L_b <= Z_b <= U_b and weights are positive, then L_1/(L_1+U_0) <= P(q dot h=1 | evidence) <= U_1/(U_1+L_0). Intersecting valid weight intervals with the independent-factor bounds preserves soundness. No guarantee that larger mini-bucket cap monotonically improves bounds under a changing grouping heuristic.

LOGRANK-BPD-16 reproduces 6,120 weight bounds and 2,880 event intervals, with 4,760 exact weight enclosures and 2,240 exact event enclosures, plus 98,304 exhaustive 12D states and 1,080 fixture comparisons.
