# Exact selective separator-message invalidation

Source: https://github.com/MoralityLabAI/LoopedTransformers/tree/cec5535dbd5d9f7763530042ed74c5bbc7ef3968/experiments/logrank_bpd_20.

Fix an elimination tree with running intersection and assign each factor to exactly one containing bag. For directed edge i->j, remove the undirected edge and denote its source component by T(i|j). Its separator message is the contraction of precisely the factors owned in T(i|j), conditional on the shared separator variables. If factor values change at a set O of owning bags, retain the old message whenever T(i|j) intersects O trivially. Its summands are identical. For every other direction discard the cached message, regardless of whether the numerical value would actually change. Recompute recursively from the new local factors and retained valid incoming messages. Induction on source-side tree size proves that each recomputed message equals its fresh exact contraction. Consequently all exact signed path contractions remain valid. For a single changed owner, exactly one direction on each edge is marked; it is the direction pointing away from the owner. Multiple updates take the union. This rule assumes fixed scopes, tree, owner map and probability model. Changes to those must be versioned or recompiled. Eviction of a valid message merely incurs recomputation. The rule does not justify reusing signed query-specific messages with a different source or epoch.

20: 27 worlds, 36 structured conditions admitted, 18 dense conditions refused, four epochs with one extra noisy reading on an existing mask before each later epoch. Audit: 2304 independent query references, 23040 arm-query comparisons, 972 invalidation set checks, 286054 logical cache transitions. At 96D hubs, 1MiB selective invalidation reduced mean counted arithmetic 12.3% versus flush. The 64KiB heuristic value cache reduced arithmetic 22.0% versus LRU but increased mean runtime 3.9%. Three roots per stratum and fixed-order single timings; no statistical superiority or native training claim. Logical retained-table cap excludes temporary tables and allocator overhead. Written proof, not Lean formalized.
