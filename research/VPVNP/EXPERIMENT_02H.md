# VPVNP-02H: canonical full-rank character recurrence

Registration 2026-11-24. Parents: 02F signed frame reduction and 02G rank-normal-form invariance. Their exact CI checks passed at 4018cae; native gates still running at registration. Nothing in this registration presumes that these gates have passed.

Define the tail-diagonal representative B(n,k) with a one at coordinates i where n <= i+k, zero elsewhere. For k<=n its rank is k. Its last entry at (n+1,k+1) is one; deleting the last coordinate gives B(n,k). H1: explicit coordinate splitting V(n+1) ≃ V(n)×F2, and an actual equivalence between matrix units and ordered frames. H2: identify the canonical trace character with the signed frame average. The distinguished normal is the last coordinate unit; its kernel is V(n) embedded with last coordinate zero. Identify the restricted kernel-basis average with the lower-dimensional canonical trace average, via an explicit equivalence of basis types. H3: specialize the 02F recurrence to obtain C(n+1,k+1)=-C(n,k)/(2^(n+1)-1), with C(n,0)=1. Prove the finite product solution and the tail diagonal rank. Apply 02G rank invariance to arbitrary coefficient matrices. All identities must pass native proof and axiom audit before claiming certification.

Independent exact H regression: all full ordered frames and canonical tail coefficient ranks, dimensions 0 through 4. Compare the literal trace on actual matrices, the prefix/last character factorization, signed kernel transport and the closed formula. Verify n=0 convention (one empty frame, character +1). In addition, test each possible diagonal marking mask through n=4 and compare to its tail representative. Archive per-dimension counts and signed sums. No fitting.
