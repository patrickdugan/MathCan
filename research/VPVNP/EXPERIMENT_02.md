# VPVNP-02A: preregistered exact rank geometry

Registered 2026-11-24 before evaluating the pilot. For V = Mat_n(F2), define D_f(r)^2 = E_{A uniform, W uniform rank r} ||f(A+W)-f(A)||^2 for arbitrary Euclidean observation f. A nonconstant f ensures D_f(1)>0. The flat/contracting theorem in upstream concerns tensor spectral prices, a different domain. This experiment studies the Euclidean observer restriction and tests whether contraction is automatically induced by the observer class.

Primary exhaustive sizes n=2,3; registered stress n=4. Enumerate every matrix, stratify by exact F2 Gaussian elimination. For each dual rank k=1,...,n and each increment rank r=1,...,n, count parity-one pairings against diag(I_k,0), normalized by the number of increments. The GL left/right action makes this representative sufficient for all dual matrices of rank k. Use exact fractions throughout.

H1: every rank-one response is positive and agrees with the rank-one formula in EUCLIDEAN_RANK.md. H2: every full-rank response agrees with the full-rank character formula. H3: maximal full-rank/rank-one squared response equals 2(1-2^-n) < n at each registered size. H4: direct enumeration for a nonlinear vector observation at n=2 agrees with its Walsh spectral expression at every nonzero rank. Negative controls: rank metric has ratio n^2 and sqrt(rank) metric has ratio n; both are valid translation-invariant metrics (subadditivity of rank and square root), with no assertion that either is a tensor price. Constant observers have undefined ratios and are excluded with explicit status. Each hypothesis must pass separately; a failed formula or count blocks the analytic extension. No GPU, training, or tuning.

Because H3 is an automatic bound for Euclidean observers, a low ratio alone cannot count as evidence for a neural mechanism.
