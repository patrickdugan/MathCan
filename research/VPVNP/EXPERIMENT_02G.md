# VPVNP-02G: trace character invariance and rank normal forms

Registered 2026-11-24 before new Walsh transform evaluation. 02E's repaired [native gate](https://github.com/patrickdugan/MathCan/actions/runs/45335169607) passed. 02F's [exact oracle](https://github.com/patrickdugan/MathCan/actions/runs/45335169599) passed, but the native log identified two local proof issues (a reducible sigma projection and branch-local simp arguments); this commit repairs them.

G1: for any finite square matrix index I, define T(B)=|GL|^{-1} sum_{W in GL} bitSign(trace(BW)), with units in the matrix ring representing GL. Show T(UBV)=T(B) for matrix units U,V by cyclic trace and the bijection W -> V W U. Simultaneous reindexing preserves T by transport of units along Matrix.reindexRingEquiv. These are actual finite sums, no oracle for the normal form.

G2: use Mathlib's Matrix.exists_rank_normal_form to put B into a block identity/zero form after multiplication by two units and simultaneous reindexing. Thus T depends only on the dimension and rank. Formalize reduction to a common block matrix for two coefficients of the same rank, including rank zero. The pairing used by the earlier Walsh modules is trace(B^T W), so a transpose bridge and rank invariance of transpose transfer this result to the entrywise character convention.

G3: independently calculate the Walsh transform of the indicator of GL(n,2) on the entire matrix vector space for n=1,2,3,4. Every dual coefficient, including zero, must agree with the formula from 02C and with all other coefficients of equal rank; direct signed summation at n<=3 must agree with the fast Walsh transform. Check all ranks for the rank-one increment indicator as well. Run one FWHT for the full-rank indicator and one for the rank-one indicator; n=1 uses the same stratum but both checks remain defined. All exact integer arithmetic, no fitting. Archive every rank's count, character sum, and exhaustive dual coefficient count. Extend the recurrence result to arbitrary normals only after native check and the actual canonical recurrence bridge. No neural lower bound claim.

Next: canonical ordered-frame recurrence in matrix coordinates, rank-one outer-product count and direct composition with the certified spectral mixture. This phase removes the need to formalize restriction independence for every arbitrary coefficient matrix individually: rank normal form permits using a single convenient canonical representative per rank.
