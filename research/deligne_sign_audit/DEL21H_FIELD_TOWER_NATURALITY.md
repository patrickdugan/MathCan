## The original scheme and point tower

Let `A = K[z_i]/I` be the **actual original DEL-16 quotient coordinate ring** of the embedded product `U^k`. Here `I` is generated by the lifted `copyEquation f t` for every `t : EqCoord k r`, without replacing `I` by its radical or dropping redundant polynomials. For a field extension `L/K` and an `L`-valued point `u` of the original equations, DEL-21G constructed `p_L : A →ₐ[K] L`. Given any `K`-algebra field homomorphism `φ : L →ₐ[K] M`, the induced `M`-point has coordinates `φ ∘ u`.

`Deligne21H.geometricPoint_tower` proves that the `A`-algebra structure on `M` induced from the original quotient evaluation equals the composite `A → L → M`, furnishing `IsScalarTower A L M`. The theorem relies on DEL-21G's previously kernel-checked `productGeometricPoint_map`.

All relative Kähler modules below are `Ω[A/K]`, with the **original base field K**. We do not silently replace them by `Ω[A/L]` or `Ω[A/M]`.

## Kähler tensor associativity

```
M ⊗[L] (L ⊗[A] Ω[A/K]) ≃ₗ[M] M ⊗[A] Ω[A/K].
```

Its kernel-checked pure tensor formula is

```

```

## Natural cotangent-fiber quotient diagram

Write `n = k·s`; for each original lifted defining equation `g_t`, let

```
R_u = span_L { (aeval_u (pderiv_i g_t))_i : t ∈ EqCoord k r }
Q_u = L^n / R_u.
```

DEL-21G proved `e_u : Q_u ≃ₗ[L] L ⊗[A] Ω[A/K]` from the genuine Mathlib differential presentation and its full original relation ideal. DEL-21H defines

```
geometricCotangentTowerEquiv :
    M ⊗[L] Q_u ≃ₗ[M] Q_(φ∘u)
```

by base-changing `e_u`, applying the *actual* Kähler tensor associator and composing with `e_(φ∘u)⁻¹`.

The central theorem is `geometricCotangentTower_coordinate_square`, an equality of `M`-linear maps:

```
geometricCotangentTowerEquiv ∘ (mkQ R_u).baseChange M
  = (mkQ R_(φ∘u)) ∘ fieldTowerCoordinateEquiv φ
```

where `fieldTowerCoordinateEquiv : M ⊗[L] L^n ≃ₗ[M] M^n` is built from the base-changed finite coordinate basis, with `1 ⊗ v ↦ (i ↦ φ(v_i))`. The equality was checked on *every* original coordinate basis vector and extended to the whole module using the Mathlib basis extensionality theorem. It is therefore a naturality statement for the genuine quotient, independent of the fact that the equivalence itself was defined by composing Kähler isomorphisms.

For a class `[v] ∈ Q_u` and `m ∈ M`, this commuting square implies the familiar representative transport `m ⊗ [v] ↦ [i ↦ m·φ(v_i)]`. The standalone explicit pure-tensor rewrite is left as a possible convenience lemma; the complete linear-map square is already in the kernel.

## Dual Jacobian tangent base change

Let

```
T_u = { v ∈ L^n : ∀ t, ∑_i aeval_u(pderiv_i g_t) · v_i = 0 }.
```

DEL-21G proved a canonical `L`-linear equivalence `Dual_L Q_u ≃ₗ[L] T_u`.

The function `geometricJacobianTangentTowerEquiv` **dualizes the proven cotangent tower equivalence**, using Mathlib's `IsBaseChange.of_equiv` and `IsBaseChange.toDualBaseChange` for the finite free quotient `Q_u`. It gives a genuine `M`-linear equivalence

```
M ⊗[L] T_u ≃ₗ[M] T_(φ∘u).
```

The separately kernel-checked theorem `geometricJacobianTangent_map_mem` proves that the coordinatewise field-homomorphic image `i ↦ φ(v_i)` obeys **every** original Jacobian equation over `M`. The theorem `geometricCoordinatePairing_map` proves that the canonical finite-coordinate evaluation pairing commutes with `φ`:

```
∑_i φ(v_i)·φ(w_i) = φ(∑_i v_i·w_i).
```

An additional explicit comparison that identifies the image of each `1 ⊗ v` under the dual-defined tangent equivalence with the coordinatewise `φ(v)` is a separate diagram-chasing convenience theorem; the full dualized isomorphism, coordinatewise tangent preservation, and pairing equality are each kernel-checked independently.

## The base-field specialization

`geometricConormalRelations_self` proves that when `L=K`, the geometric conormal relation space is exactly `Deligne21D.conormalRelations`; `geometricCotangentSelfEquiv` is the corresponding quotient equivalence, and `geometricCotangentSelfEquiv_mk` proves it fixes the class of every coordinate vector. The original full-ideal conormal equations agree with DEL-21F at the level of the quotient presentation. A separate equality of the *two implementation-specific quotient-to-Kähler isomorphisms* is not claimed by this specialization theorem.
