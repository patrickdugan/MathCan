# DETFACT-13: abstract arena certificates and exact structural work profiles

Status: descriptive feasibility gate PASS, warm speed gate FAIL. Standalone Lean source is a proof candidate, not a kernel-checked result. This extends the synthetic supplied-exponent execution audits; it does not reproduce Cogentic's relation producer.

## 1. Abstract resource theorem

For modulus and exponent limb counts L,E, batch b, root bound r=floor(sqrt(K)), and actual segment slots c=min(S,floor((K-1)/2)), the arena has exactly 4*((b+8)*L+E+2)+r+1+c requested bytes. The six individual L-limb arrays, 2L+2 scratch limbs, bL residues and E exponent limbs sum to (b+8)*L+E+2. Each assigned half-open interval is disjoint from its adjacent interval and a byte access (or multi-byte access) known to stay inside its slice stays inside the arena. For positive finite caps and a grid with minimum c0, some configuration is feasible iff the minimum configuration is feasible. This follows because all other arena terms are independent of c. Width W does not change the arena formula in this particular uint64_t chunk implementation.

At the worker's domain maxima L=E=128, b=128, r=3162, c=4999999, the formula gives 5,073,314 bytes. This is below 2^32. The schoolbook and Montgomery inner multiply-add also fits a uint64_t: with radix B=2^32 and four words a,b,c,d in [0,B-1], a*b+c+d <= (B-1)^2+2(B-1)=B^2-1. The standalone Lean module MathCan/DETFACT13Arena.lean encodes these abstract arithmetic obligations and prints selected axiom dependencies. It assumes the parser/domain bounds and per-access index premises. It does not model C pointer semantics, Montgomery correctness, allocation success or the stack. No Lean executable was available and the network could not resolve the toolchain download; run `lake env lean MathCan/DETFACT13Arena.lean` with the pinned repository toolchain. Keep this candidate outside the aggregate library until checked.

## 3. Structural cost model

For left-to-right binary powering initialized at the base, the exact modular multiply count is bitlen(e)+popcount(e)-2 for e>=1. For each candidate action (S,W), reproduce the odd prime-power stream and conservative chunk packing, with a flush at each segment boundary. Sum the binary costs for every emitted chunk. Add the cost of the odd part of the supplied exponent and multiply by b. This predicts the worker's reported Montgomery multiplication counter before conversion/splitting; similarly predict power calls, emitted odd prime powers and segment count. The independent profiler uses a full sieve, unlike the native segmented worker. Its cache and cold allocation costs are outside the arena budget, so this is not a certified total-memory scheduler.

Fit nonnegative least squares on training native kernel medians using scaled features: multiplication count times L^2 and L, power calls times L, sieve marking writes, candidate scans, segment count, K, batch times L^2 and intercept. Choose the lowest predicted cost within the exact feasible grid; tie by arena size then action. Certified minimum chooses smallest arena, then larger W, then action ID. Nine training and twelve held-out workloads use disjoint K/batch/modulus/exponent levels with all intended levels represented. Test K=2048/8192/16384, modulus 127–512 bits, batch 2/4/8, exponent 96/256/512 bits. Six unchanged DETFACT-12 actions, six caps 512–8192 bytes. Three shuffled grid repeats. Write protocol before training and freeze weights and decisions before test timings. Primary gate is complete feasible coverage, preflight abstention on infeasible cases, zero overcap and exact counter agreement. Secondary gate requires warm paired capped dispatch ratio <=0.99. These are local phase freezes, not external preregistration. No held-out performance was used in model fitting.

All 378 grid invocations matched four native counters and the independent Python oracle (1548 residues, 1548 first split results). All 366 capped runs matched the oracle. Both policies completed 61/61 feasible pairs and abstained on the 11 grid-infeasible pairs. Neither exceeded the native arena cap.
