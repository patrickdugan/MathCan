# NOR-31: equal search resources, independent calibration root and a leaked evaluation root

Companion to [Compactification-Theory NOR-31 PR #199](https://github.com/MoralityLabAI/Compactification-Theory/pull/199). The previous [NOR-29 PR #119](https://github.com/patrickdugan/MathCan/pull/119) proved a finite min-expectation gap for root-aware batch-fixed attacks. NOR-31 extends that argument to explicitly match calibration samples and tie-break search restarts.

## Finite matched-root experiment as a game

The calibration root c and actual evaluation root e are distinct random variables. Let t range over matched attacker tie-breaking restarts. A pre-root committed attack is A(c,t). A leaked-root attack is B(e,t). The two arms face exactly the same audit batch generated by e, and each alteration remains fixed over that complete batch.

For each evaluation root e, the batch-dependent nonnegative loss L(a,e) counts how many coefficient changes are detected by the audit schedules under root e. If the leaked-root choice is **globally optimal for each e and t**, then

    L(B(e,t),e) ≤ L(A(c,t),e)

for every independent calibration root c. Summing over finite calibration roots, evaluation roots and matched ties gives

    Σ_c Σ_t Σ_e L(B(e,t),e)
      ≤
    Σ_c Σ_t Σ_e L(A(c,t),e).

This is the exact finite counterpart to E_e min_A L(A,e) ≤ E_c,E_e L(A(c),e).

The premise requires a genuine optimal conditional attack. **NOR-31 uses a fixed greedy approximation**, with the same 512-schedule budget and tie seeds in both conditions. The Lean result does not guarantee that this approximate leaked-root algorithm wins on every source. A separate theorem constructs a deliberately poor root-aware algorithm in the two-root game that loses even to a fixed blind strategy. This limitation is material when interpreting the empirical source-level win count.

## Strict two-root witness

In the binary exact-coordinate toy game, the root chooses which of two possible coordinates is checked. A root-aware attack picks the uninspected coordinate and is detected zero times across the two possible evaluation roots. Every fixed attack chosen from independent calibration information is detected exactly once. The strict advantage remains after averaging over any calibration-only Boolean algorithm and matching both Boolean tie restarts.

## Commitment timing

NOR-28 abstract binding requires equal salted commitment digests to open the same altered support. A changed attack chosen after the evaluation root is exposed cannot open the earlier commitment under that hypothesis. An attacker who sees each particular audit and can change support between trials is stronger than the batch-fixed attacker treated here.

The prospective applied study plans 24 new RRC25 source identities, a fresh 256-bit calibration root first, a second independent 256-bit evaluation root only after precommitting 2,304 attacks, then 2,304 late root-aware attacks using the identical greedy search and 32 restart tie seeds per policy/source. Every attack is evaluated on the same 512 actual audit schedules. Its registered primary criterion is +1.5 percentage points hybrid paired mean reduction and at least 20/24 source-level wins. A separate-process replayer checks all 2,359,296 decisions.

The Lean module [MathCan/NOR31MatchedRootCalibration.lean](../../MathCan/NOR31MatchedRootCalibration.lean) uses the standard Lean 4.35 library and lists theorem axioms. Theoretical finite counting and commitment-binding consequences depend on their explicit hypotheses. Cryptographic SHA-256 binding, independent OS entropy, HMAC pseudorandomness, runner job integrity and the authentic exact target witness remain outside the formal claims.
